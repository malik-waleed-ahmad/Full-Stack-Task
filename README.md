# Full Stack Social Media Application

A full-stack social media web application built with PHP, MySQL,
Tailwind CSS, and vanilla JavaScript.

## Features

- User registration and authentication
- User profiles and profile pictures
- Create, edit, hide, and delete posts
- Multiple images per post
- Like and unlike posts
- View users who liked a post
- Add comments and replies
- Like comments
- Delete own comments
- Infinite scrolling feed
- Hidden posts management
- Responsive user interface
- CSRF protection
- Secure password handling

## Tech Stack

### Frontend
- HTML5
- Tailwind CSS
- JavaScript

### Backend
- PHP
- PDO

- MySQL
